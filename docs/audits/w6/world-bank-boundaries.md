# W6 World Bank Boundaries

World Bank Project Context, Project Leadership, procurement contacts, tender participants, and role history remain source facts. W6 has no import, relationship, or inference path from those tables to Firm, Expert, CandidateMatch, or CandidateParticipationRecord.

Permanent W6 coverage fingerprints the seeded Project and current ProjectRoleAssignment before participation actions and verifies the same rows afterward. Candidate creation stays an explicit W5 authority action. No leader or contact availability is inferred.
