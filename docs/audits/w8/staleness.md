# W8 Staleness Audit

A sealed pack never changes. A current read resolves the exact W7 handoff and compares scenario current state, viability, latest exact approval, analysis IDs, revision selection hash, participants, contributions, evidence identities, and exact W6 facts.

Any upstream mismatch returns `pack_current=false` with stable reasons. The permanent test supersedes an exact sealed availability fact, proves the pack becomes historical, rejects resealing the old handoff, and rejects a new ordinary export.

An explicit historical export uses only the sealed snapshot and carries `HISTORICAL SNAPSHOT`. Previously generated artifacts remain immutable and downloadable to active authorized members.
