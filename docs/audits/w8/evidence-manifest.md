# W8 Evidence Manifest Audit

Every manifest item has an ordinal, category, source authority type, stable source identity, provenance, purpose, review/evidence state, optional Requirement/Position/Gap IDs, source hash/version where available, and canonical payload.

The deterministic manifest covers current Requirements/Positions and Gap outcomes; Lead Organization, Partner Firms, Experts; ProjectReference and CVVersion identities; exact W6 facts; source/private documents; company snapshot authority; later obligations; and source-backed forms. Empty evidence cells remain empty and disclosed.

The pack hash is SHA-256 over the canonical manifest. Items are stored independently from mutable upstream tables and protected by database immutability triggers.
